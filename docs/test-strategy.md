# 测试与质量门禁

## 质量目标

产品不承诺所有 PDF 都能无人工完成导入；它承诺错误可发现、可定位、可修正，并且不未经确认进入正式题库。

| 指标 | MVP 门槛 |
| --- | --- |
| 已确认作答保存成功率 | ≥ 99.9% |
| 正式题来源可追溯率 | 100% |
| 已发布答案准确率 | ≥ 99.5% |
| 已发布题干/选项完整率 | ≥ 99% |
| 重试产生重复题 | 0 |
| 修改题目破坏历史结果 | 0 |

若识别质量未达到门槛，系统应提高人工审核比例，而不是降低发布门槛。

## 自动化测试层次

### 单元测试

- 单选、多选完整集合判定。
- 题目规范化、指纹和重复检测。
- 错题与连续答对的掌握状态规则。
- 题号、选项、答案标记和页眉页脚解析。
- 权限、幂等键和离线冲突规则。

### 契约测试

- Web/API 请求与响应 Schema。
- Worker 阶段消息和状态转换。
- 模型输出必须通过题目 JSON Schema。
- 数据库迁移可前进、可在测试库重建。

### 集成测试

- 上传 → 任务 → 草稿 → 校对 → 发布 → 练习。
- OCR 超时、单页失败和任务重试。
- 私有文件与签名 URL 权限。
- 修改题目后，旧作答仍引用旧修订。
- 同一作答事件重复同步只保存一次。

### 端到端测试

- 手机与电脑完成普通练习和模拟考试。
- 多选未确认时不能意外提交。
- 刷新、短时断网、登录过期与恢复同步。
- 倒计时结束自动交卷且答案不丢失。
- PDF 双栏校对、题目合并/拆分和发布阻断。

## PDF 黄金样本

样本必须覆盖文本、扫描、混合、单栏、双栏、跨页、表格、图片、代码、旋转、模糊、重复页、答案集中在文末等情况。

人工标注数据至少包含题目边界、题干、选项、答案、解析、图片关系和页码。每次修改解析器、OCR 配置或模型提示词，都生成结构化 diff 并比较：

- 题目边界 F1；
- 题干字符准确率；
- 选项完整率；
- 答案精确匹配率；
- 解析与图片关联准确率；
- 跨页归并准确率；
- 每 100 题人工校对时间。

任何真实纠错都应匿名化后加入长期回归样本。

## 合并与发布门禁

每个功能变更必须同时具备：验收标准、测试、代码审查和无高优先级缺陷。涉及数据库的变更需要迁移验证；涉及 PDF 的变更需要黄金样本回归；涉及做题交互的变更需要至少一个手机视口端到端测试。

生产发布前还需通过依赖与容器扫描、备份恢复演练、无障碍检查和基础性能测试。
