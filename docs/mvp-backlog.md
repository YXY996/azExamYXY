# 首版实施清单

## 里程碑 0：真实样本验证

- [ ] 提供 3–5 份不同版式的 AZ-104/AZ-305 PDF。
- [ ] 选取 20–30 个代表页面做探索。
- [ ] 人工标注 100–200 道题形成黄金样本。
- [ ] 确认单选、多选、图片题和答案册版式。
- [ ] 用样本验证题目 JSON Schema 与校对流程。

退出条件：能够用一种真实 PDF 演示“抽取候选 → 对照原页修正 → 发布”。

## 里程碑 1：可运行骨架

- [ ] 建立 Next.js PWA、数据库迁移和测试框架。
- [ ] 完成登录、私人题库和行级权限。
- [ ] 建立私有 PDF 上传和 `import_jobs` 状态查询。
- [ ] 建立 Python Worker 骨架及本地开发环境。
- [ ] 建立 CI：格式、类型、单元、契约和迁移测试。

退出条件：登录用户能上传 PDF，看到后台任务状态，且不能读取其他用户文件。

## 里程碑 2：第一条纵向链路

- [ ] 原生文本 PDF 解析与页图生成。
- [ ] 单选、多选题切分和确定性校验。
- [ ] 校对工作台：原页与字段并排、编辑、确认、发布。
- [ ] 顺序练习、确认答案、解析和自动保存。
- [ ] 手机响应式适配。
- [ ] 对第一份真实 PDF 执行黄金样本回归。

退出条件：用户能从真实 PDF 生成至少 50 道已确认题，并在手机完成一次练习。

## 里程碑 3：复习与稳健导入

- [ ] 扫描页 OCR 与混合页处理。
- [ ] 单页失败重试、幂等导入和重复题提示。
- [ ] 错题、收藏、连续答对掌握状态。
- [ ] 随机练习与模拟考试。
- [ ] JSON 导出、软删除与恢复。
- [ ] 关键监控、备份与恢复演练。

退出条件：文本与扫描样本均能完成导入；失败可定位和重试；一周真实学习数据不丢失。

## 第一批可并行任务

这些任务在共享 Schema 批准后可以分别交给不同 agent：

1. UX：做题页和校对工作台响应式原型。
2. Web：登录、题库列表和上传状态页面。
3. Database：题目版本、来源、答题和复习状态迁移。
4. Worker：PDF 预检、页分类、原生文本和页图输出。
5. QA：题目 Schema 契约测试与黄金样本工具。
6. Security：上传隔离、私有文件访问和日志检查。
