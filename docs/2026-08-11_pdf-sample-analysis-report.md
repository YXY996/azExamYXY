- 题目通常以 `Topic N` 与 `Question #N` 开始，并持续到下一个题头。
- 181 页没有题头，其中包括跨页续题、图片页和真正空白分页，不能按“一页一题”切割。
- 案例题可能连续四页；普通题也可能跨页展示 Answer Area。

## 数据质量风险

- 没有答案键：所有 `correct_option_ids` 初始为空，答案状态为来源缺失。
- 图片中的蓝色选中状态可能是界面现状或默认控件，不能视为答案。
- 固定 Logo、水印与页眉会污染 OCR，需要在显示层过滤但保留原始证据。
- Topic 15 缺少显示题号 2；显示编号不能被当成连续数据库序号。
- 检测到多组疑似重复题，需要结合图片和题干哈希人工判定。

## 推荐解析管线

1. 校验 PDF 哈希并登记不可变源版本。
2. 提取带坐标的原生文本，同时按 150–200 DPI 渲染页面。
3. 用题头状态机合并续页；跳过无文本且无图片的空白分页。
4. 过滤固定页眉、Logo 和水印，裁取非固定图片与 Answer Area。
5. 仅对缺失文字的相关区域 OCR，不对整本 PDF 无差别 OCR。
6. 自动结构化普通单选、多选和判断题；复杂交互题保留图片与交互描述。
7. 人工校对题干、选项、图片边界和正确答案，记录答案来源后才允许发布。
